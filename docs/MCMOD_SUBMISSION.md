## 提交注意

1. 概述必须写明第三方非官方附属，避免被误认为本体官方续作。
2. 「官方状态」不要乱填，百科文档对此有明确警告。
3. `LICENSE` 文件当前版权署名为本体作者 TartaricAcid，走「使用协议」授权前需改为自己，否则授权链条不成立。
4. 站内上传 jar 需要编辑员权限。建议先提交模组页面并外链 GitHub Releases，站内下载后补。
5. 编辑器支持 `Ctrl + Enter` 快速提交、`Alt + X` 自动链接。
6. 提交后进审核队列，站内日均审核量七百上下，通常一到两天出结果。
