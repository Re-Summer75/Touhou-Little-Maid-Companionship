# 女仆交互按键

本功能重新分配主人对已驯服女仆的右键交互，避免打开界面、坐下和物品操作使用相互冲突的按键。

## 基础按键

| 操作 | 按键 |
| --- | --- |
| 打开女仆界面 | Shift + 右键 |
| 坐下或起立 | 空手右键 |
| 让女仆离开载具或放下乘客 | 女仆骑乘时空手右键 |
| 使用手中物品与女仆交互 | 手持物品右键 |

普通右键不再回退打开女仆界面。手中的物品没有女仆交互效果时，不执行操作。

## 食物和药品

| 物品 | 新按键 | 行为 |
| --- | --- | --- |
| 可用工作餐 | 对准面部下方后右键 | 直接喂给女仆，并恢复附属饥饿值 |
| 金苹果或附魔金苹果 | 对准面部下方后右键 | 喂食并保留原有效果和进度触发 |
| 蛋糕 | 对准面部下方后右键 | 消耗一整个蛋糕，按 7 片蛋糕的总营养恢复饱食度和饱和度 |
| 药水 | 右键 | 将药水效果应用给女仆 |
| 牛奶桶 | 右键 | 清除女仆的药水效果 |
| 玻璃瓶 | 右键 | 提取 1 瓶女仆经验 |

Shift + 右键这些物品时统一打开女仆界面，不再执行喂食或药品操作。

饱和度达到 `100` 后，所有口部喂食都会由服务端拒绝且不消耗物品。当前本体没有跨 Bedrock 和 Gecko 模型通用的专用拒绝动作，因此使用兼容回退：女仆看向玩家、挥动副手、播放拒绝音效，并显示“已经吃不下了……”气泡。动作和音效有 `20 tick` 冷却，气泡存在期间不会重复添加。

### 面部喂食区域

附属在模型完成当前帧动画后，从 `head` 或 `Head` 骨骼实际提交给渲染器的立方体顶点建立归一化区域：

- 水平方向只接受正中央的 40%，即 `U = 0.30～0.70`。
- 垂直方向只接受从正面底边向上的 20%，即 `V = 0.00～0.20`。
- Bedrock 模型直接捕获头部立方体六个面的最终渲染顶点，并按动画后头骨骼的局部正面选出面部。
- Gecko 和可访问骨骼的 YSM 模型直接读取动画后的 `Head` 网格顶点和边向量。
- 判定平面直接贴在头部主体立方体正面，跟随工作动作、左右转动、俯仰、坐下、骑乘和模型缩放。
- 不再自行解析模型 JSON 或推测坐标，因此目录模型包、ZIP 模型包和不同格式使用相同的最终顶点判定。
- 判定只接受最近一秒内由渲染层更新的动态区域；没有有效动态区域时禁止喂食，不再回退到可能偏移的静态坐标。
- 平面计算不依赖四个顶点的顺序或绕向，只根据四点形成的面和动画后的头部向上方向定位底边。
- 仅在开启 `F3 + B` 判定箱调试时，四个面部顶点显示为红、绿、蓝、黄实心方块，面部底部中央的 `40% × 20%` 喂食区显示为橙色二维平面。
- 客户端喂食命中直接使用准星射线与这块橙色平面的交点，不再使用旧的世界坐标判定区域。

客户端只在准星进入该区域时发送女仆实体、区域坐标，以及橙色平面中心和法向量的三维世界坐标。它们都由 Minecraft 实际使用的相机视图矩阵精确逆变换得到，不使用玩家手部位置或女仆实体的固定朝向。服务端会复核区域坐标、面部中心位置、法向量、所有权、距离、视线和当前瞄准实体。成功喂食后以橙色平面中心作为对应食物碎屑的生成基准点，并以该平面的世界法向量向下偏转 `45°` 作为低速粒子锥体中心轴。碎屑尺寸为原版物品粒子的 `75%`，初速度进一步减半，横向散布范围大幅扩大，使效果更接近进食时掉落的碎屑。创造模式下仍会触发喂食效果，但不消耗手中食物。

女仆本体的 Work Meal、Heal Meal 和 Home Meal 在完整进食过程中也会复用同一套碎屑效果。普通食物在开始使用约 `7 tick` 后，按原版每 `4 tick` 一组的节奏持续发射到进食结束；快速食物不等待预热。每组粒子都会从该女仆当前动画帧的面部平面重新取得中心与法向量。面部数据尚未建立时会等待最多 `20 tick`，同一女仆的待处理效果会合并，并在进食已经结束时丢弃，不会延迟喷出或回退到固定实体坐标。玩家直接喂食仍然只发射一组。附属会阻止 `LivingEntity` 为女仆生成旧位置的原版进食碎屑，避免两套效果重叠；本体已有的治疗、爱心等业务提示粒子仍然保留。

## 原版物品交互

以下普通右键行为继续交给车万女仆本体处理：

- 穿戴或卸下背包。
- 鞍、智能符板和命名牌。
- 普通指南针的任务区域操作。
- 相机、仆人铃和模型切换器。
- 好感度工具。
- 其他模组实现的 `interactLivingEntity` 行为。

如果本体事件没有处理物品，附属会先调用物品的实体交互；仍未处理时再调用物品的普通右键使用逻辑，使雪球、鸡蛋、末影珍珠和喷溅药水等投掷物在对准女仆时仍能正常投掷。最后阻断原版“打开 GUI”兜底。

## 河童罗盘例外

河童罗盘保留本体专用按键：

- 普通右键女仆：写入日程位置。
- Shift + 右键女仆：清除女仆日程位置。

因此手持河童罗盘时，Shift + 右键不会打开女仆界面。

## 准星提示

附属通过车万女仆的 `MaidTipsOverlay` 扩展入口覆盖相关提示：

- 空手时同时显示坐下和打开界面的按键。
- 普通食物只在准星进入面部喂食区域时显示提示。
- 金苹果提示会说明需要先对准面部下方。
- 药水和牛奶提示改为普通右键。
- 玻璃瓶提示只说明普通右键提取 1 瓶经验。
- 普通可用食物会显示喂食提示。
