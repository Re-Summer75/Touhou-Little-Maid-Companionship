# 女仆状态反馈系统

本功能为“女仆扩展”提供独立饥饿值、自动进食、低耐久工具替换、状态气泡和短暂请求动作。

## 饥饿规则

| 项目 | 数值 |
| --- | --- |
| 初始与最大饥饿值 | 100 |
| 自动进食阈值 | 40 |
| 工作消耗 | 每 200 tick 降 1 |
| 空闲消耗 | 每 400 tick 降 1 |
| 休息或睡眠 | 不消耗 |
| 食物恢复 | 原版营养值 × 5 |

饥饿只在女仆实体实际加载期间计算，不会在区块卸载后继续下降。

当饥饿值不高于 40 时，女仆会：

1. 检查当前手中的食物。
2. 检查可用背包中的食物。
3. 复用车万女仆 Work Meal 的食物处理器和黑名单。
4. 找到食物时自动进食。
5. 没有食物时显示“我需要食物……”。

本体 Work、Heal 和 Home Meal 产生的正常进食也会恢复附属饥饿值。

首版饥饿值不会造成扣血、减速或强制停工。

## 工具规则

检查范围：

- 主手
- 副手
- 不检查护甲和饰品

警戒线：

```text
剩余耐久 ≤ max(10, 最大耐久的 10%)
```

进入警戒线后：

1. 扫描女仆可用背包。
2. 只查找相同物品 ID 的备用工具。
3. 候选工具必须高于耐久警戒线。
4. 多个候选中选择剩余耐久最高的一个。
5. 新工具放入原手，旧工具放回候选所在槽位。

没有备用工具时，女仆继续当前工作，但会显示包含剩余耐久比例的进度气泡。

正在使用物品时不会交换工具，以免打断弓、食物等使用流程。

## 气泡规则

| 项目 | 行为 |
| --- | --- |
| 状态优先级 | -1 |
| 显示时间 | 15 秒 |
| 重复冷却 | 60 秒 |
| AI waiting 存在时 | 状态气泡让路 |
| 删除规则 | 只删除本功能记录的气泡 key |

低优先级保证状态提示不会在气泡槽已满时挤掉 AI 等待或回复。

状态类型：

- 缺食物：文本气泡。
- 工具低耐久：进度气泡。
- 自动更换成功：文本确认气泡。

## 动作规则

缺食物或工具没有备用时，如果主人在 8 格内：

1. 女仆停止当前导航。
2. 看向主人。
3. 进入祈求动作 60 tick。
4. 时间结束、主人离开、女仆睡眠或死亡时恢复。

女仆不会主动走向主人。

自动更换工具成功时只挥动对应手，不进入祈求状态。

如果缺食物和工具告警同时发生，工具告警拥有更高的动作优先级。

## 数据与同步

- 饥饿值存入 TLM `TaskDataKey`，随女仆 NBT 保存并同步。
- 气泡、冷却、待恢复营养值和动作计时只保存在服务端运行时。
- 气泡通过 TLM `ChatBubbleManager` 自动同步。
- 祈求动作通过 TLM `DATA_BEGGING` 自动同步。
- 本功能不新增网络包。
- 本功能不使用 TLM 当前未参与业务的 `EntityMaid.getHunger()`。
