## 维护约定

- 新增开发文档统一放在本目录。
- 同一主题的文档放入独立子目录，并通过该目录的 `README.md` 建立索引。
- 表情、动作、GUI 等不同系统不得继续堆放在同一文件中。
- 文件名使用大写英文和下划线，便于与源码、资源目录区分。
- 文档应注明所依据的 Minecraft、Forge 和车万女仆版本。
- 升级车万女仆依赖后，应重新核对源码路径、动画名称和触发条件。
