## Gecko 骨骼二级物理

客户端启用物理后，Gecko 女仆的软体骨骼可产生二级摆动：

- 头发、双马尾和发饰。
- 尾巴和耳朵。
- 裙摆、围裙和丝带。
- 披风、翅膀及模型作者标记的其它链。

摆动由实体移动、起步/急停、转身、跳跃、作者动画加速度和环境风共同驱动。
静止时唯一平衡点是模型作者姿态，不额外施加恒定重力造成二次下垂。

限制：

- 只作用于 Gecko 模型。
- Bedrock JS 和纯 YSM 模型不写入骨骼物理。
- 相机超过 24 格时不执行近距离求解。
- `physics.enabled=false` 后立即移除上一帧物理覆盖，回到作者动画。

自动发现会保守排除低置信度骨骼；复杂模型可用 sidecar 明确指定软体链。

客户端配置：

```toml
[physics]
enabled = true
```

文件：`config/tlm_companionship/client.toml`

## 物理约束与碰撞

可见约束包括：

- 每根骨骼按力臂限制最大末端位移，长发不会因相同角度甩得过远。
- 非对称摆角减少头发、发饰或裙摆向身体内部倒入。
- 模型头部、身体或元数据代理阻止常见穿模。
- 裙摆分支使用链间距离约束，减少布片分离和互相穿插。
- 碰撞投影持续无进展且偏差超过阈值时，沿缓存的近作者合法姿态回收。
- 大帧间隔把单帧积分步长限制在约 1 game tick，并在时间轴断层时重置惯性输入；
  高速碰撞只做有限扫掠采样，不启用全局物理子步进。

模型包可以提供 schema 3 sidecar：

`assets/<namespace>/tlm_companionship/physics/<model>.json`

未提供元数据时，系统根据几何、拓扑和名称提示保守发现可动链。

## 程序化环境风

环境风只通过客户端骨骼物理影响外观：

- 同一场景共享宏观风向。
- 不同女仆和骨骼使用不同相位，避免整齐同步摆动。
- 维度、天气、雷暴、海拔会改变风强。
- 室内和浸水会显著衰减风。
- 头部壳层等刚性保护骨不接受风偏转。
- 阵风经过滤波并受安全角限制，不长期把模型吹成固定倾斜。

风不会推动女仆实体、改变碰撞箱或影响服务端移动。

## 模型外法线与绕序修正

渲染 Gecko 模型时，附属按实际面顶点重新计算外法线和外向绕序：

- 修复部分 cube 在光影下明暗反转。
- 修复背面判定错误。
- 覆盖原版 Gecko 渲染和 Sodium/Embeddium 路径。
- 修正 TLM Sodium DOWN 法线的 X 分量打包问题。

该行为不改变模型几何、纹理或动画，只修正光照输入；Bedrock 和 YSM 不在该修正范围。

## 客户端回血闪烁修复

TLM 原有随机回血可能在客户端先显示一次、随后被服务端真实生命覆盖。
附属阻止客户端单独执行该随机回血：

- 血条不再短暂跳高后回落。
- 服务端随机回血仍然保留。
- 附属饥饿/饱和回血不受影响。

## 开发者调试

物理调试工具可显示活动骨架、碰撞代理和位移统计，也可把骨架信息写入日志。
这些工具不属于正常玩法，不会在未启用调试时改变女仆表现。
