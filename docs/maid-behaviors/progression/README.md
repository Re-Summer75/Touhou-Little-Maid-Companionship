# 成长、进度与界面行为

本页描述女仆等级、经验、好感关联、独立进度树，以及主人在女仆界面中能看到的状态。

[返回行为总索引](../README.md)

## 独立等级

每只女仆拥有 1–50 级的附属等级，并随女仆数据保存。

下一级所需经验：

`50 + 25 × (当前等级 - 1)`

达到 50 级后不再升级，并把当前升级经验归零。

### 经验来源

当前可观察来源包括：

- 女仆拾取有效经验球。
- 原版或模组进度奖励的经验。
- 管理员等级命令。
- 其它接入 `MaidLevelApi` 的扩展。

不同来源统一进入同一等级曲线。进度奖励不会给隐藏的镜像玩家，
而是直接转交到实际女仆。工作和普通交互来源目前只预留分类，没有默认经验接入。

### 升级通知

女仆升级且主人在线时，只向主人聊天栏发送：

`{女仆名} 的等级从 {旧等级} 提升到了 {新等级}`

该提示不全服广播，也不额外生成粒子或音效。

## 好感度关联

好感度仍由 TLM 本体管理，本模组读取其等级用于：

- 好感度等级至少为 1 时允许注视召回。
- 好感度等级至少为 3、饥饿值不高于 20 时启用高信任求食分支。
- 在详情提示中显示当前好感等级。
- 触发“初识”“信赖”“相伴”等女仆进度。

本模组不会用附属等级替换 TLM 好感度；两者是独立成长轴。

## 女仆主界面

### 饥饿值与饱和度

主界面状态区增加：

- 橙色饥饿值条。
- 底部亮黄色饱和度细层。
- 悬停时显示两项当前值。

界面只显示服务端同步状态，不在客户端自行推算消耗。

### 详情提示

悬停女仆“详情”入口时，在标题后补充：

- 当前附属等级。
- 当前经验/下一级所需经验；满级时显示已满级。
- 当前 TLM 好感等级。

这项修改不重排其它 TLM 详情字段。

## 每只女仆独立的原版进度

有主人的女仆会在首次需要时建立独立的原版 `PlayerAdvancements`：

- 每只女仆拥有自己的完成状态。
- 无主女仆不创建 tracker，也不写进度文件。
- 女仆离开世界、世界保存或服务器停止时落盘。
- `/reload` 会像在线玩家一样重载进度定义。

保存位置：

`<存档>/tlm_companionship/maid_advancements/<女仆 UUID>.json`

进度不存进 TLM TaskData，因此不会随女仆跨存档迁移；同一存档内正常收纳、放置和跨维度不受影响。

## 原版与模组进度桥接

女仆行为会映射到原版触发器，使原版或其它模组的进度可以自然判断女仆：

| 行为族 | 代表触发 |
| --- | --- |
| 背包与装备 | 拾取、装备、背包和饰品变化 |
| 位置与世界 | 定时位置、进入方块、跨维度、下界旅行、摔落 |
| 战斗 | 击杀、死亡、造成伤害、受到伤害 |
| 状态与物品 | 药水效果、使用/消耗物品、工具耐久变化 |
| 工作 | 钓鱼、合成、放置方块、对方块使用物品 |
| 生物互动 | 女仆促成动物繁殖 |
| 特殊世界行为 | 蜂蜜块滑行 |

触发前会把女仆当前位置、朝向、生命、状态效果、姿态和物品同步给内部镜像，
再由原版条件系统判断。女仆无法完成的条件会自然保持未完成。

### 奖励

原版进度奖励按以下方式落到女仆：

- 经验：进入女仆附属等级。
- 物品：尝试放入女仆背包。
- 聊天：遵守 `announceAdvancements` 游戏规则，以女仆显示名广播。
- 配方：女仆没有玩家配方簿，因此不保存配方奖励。

## 内置女仆进度

当前内置 12 个定义，其中包含一个根节点和以下行为线：

### 喂食

- “第一口”：成功喂食 1 次。
- “按时吃饭”：累计喂食 32 次。
- “嗜甜”：累计喂食蛋糕 8 次。

### 等级与经验

- “初出茅庐”：达到 5 级。
- “熟练女仆”：达到 15 级。
- “得心应手”：达到 30 级。
- “完美女仆”：达到 50 级。
- “勤学不辍”：累计获得 1000 点等级经验。

### 好感

- “初识”：好感等级达到 1。
- “信赖”：好感等级达到 2。
- “朝夕相伴”：好感等级达到 3。

这些定义使用四个本模组触发器：

- `tlm_companionship:maid_fed`
- `tlm_companionship:maid_level`
- `tlm_companionship:maid_favorability_level`
- `tlm_companionship:maid_experience`

具体门槛和父子关系以服务端 Data Pack 为准。

## 女仆专属进度 Tab

女仆界面顶部会占用可用 Tab 槽位打开“女仆进度”页面：

- 显示当前根进度标题和完成数量。
- 女仆专属进度树优先展示。
- 图标栏支持翻页。
- 进度树可拖动浏览。
- 服务端只向当前查看者发送该女仆可见的进度状态。

页面不是独立全屏进度界面，不改变玩家自己的进度数据。

## 旧成就迁移

旧版独立成就会在首次创建女仆进度 tracker 时静默迁移到对应原版进度：

- 不重复播放完成广播。
- 不重复发放已经领取的奖励。
- 迁移完成后以新进度文件为准。

完整的桥接表、数据格式和界面实现见[女仆原版进度系统](../../advancements/README.md)；
界面布局参考[女仆界面分析手册](../../gui/README.md)。
