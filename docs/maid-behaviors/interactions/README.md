# 主人交互与物品行为

本页描述主人如何操作已驯服女仆，以及本模组如何路由食物、药品和 TLM 本体物品。

[返回行为总索引](../README.md)

## 基础按键

| 操作 | 按键 | 结果 |
| --- | --- | --- |
| 打开女仆界面 | Shift + 右键 | 直接打开 GUI |
| 坐下或起立 | 空手右键 | 切换主人命令坐姿 |
| 离开载具或座位 | 女仆骑乘时空手右键 | 解除指挥锁并下乘 |
| 放下乘客 | 女仆载客时空手右键 | 弹出乘客 |
| 使用物品 | 手持物品右键 | 只执行物品交互 |

普通右键不再兜底打开界面。手持物品没有女仆交互时，会再尝试物品自身的 `use`；
雪球、鸡蛋、末影珍珠和喷溅药水等因此仍可正常投掷。

除河童罗盘外，Shift + 右键始终优先打开界面，不会执行口部喂食、药水、牛奶或其它
普通物品交互。

### 坐下与起立

空手右键且女仆没有载具/乘客时：

- 切换命令坐下状态。
- 坐下时停止导航并清除攻击目标。
- 起立后若存在活动限制区，可重新走向限制中心。

命令坐下优先于普通跟随、拾取和陪伴意图。它不同于坐在凳子、娱乐座或其它实体上。

### 离开载具或放下乘客

空手右键骑乘中的女仆时：

- 先解除注视指挥产生的座位/载具锁。
- 调用下乘，不额外切换命令坐姿。

女仆载着其它实体时，同一操作会放下乘客。

## 河童罗盘例外

河童罗盘继续使用 TLM 本体按键：

- 普通右键：写入日程位置。
- Shift + 右键：清除日程位置。

因此手持河童罗盘时，Shift + 右键不会打开女仆界面。

## 口部喂食

主人手持合法食物并对准动画后的口部区域右键，可直接喂给女仆。

### 可用食物

| 物品 | 行为 |
| --- | --- |
| 合法工作餐 | 恢复附属饥饿和饱和度 |
| 金苹果/附魔金苹果 | 恢复状态，并保留原版效果与进度 |
| 蛋糕 | 消耗整块，按 7 片总营养恢复 |

创造模式保留喂食效果，但不消耗物品。

### 口部区域

本模组读取模型完成当前帧动画后实际提交的面部平面：

- 水平中央 40%，即 `U = 0.30–0.70`。
- 从正面底边向上 20%，即 `V = 0.00–0.20`。
- 支持 Gecko、Bedrock 和可访问头部网格的 YSM 模型。
- 坐下、骑乘、转头、俯仰、工作动画和模型缩放都会同步更新。
- 没有最近 1 秒内的有效动态平面时禁止喂食，不回退到固定坐标。

客户端命中后，服务端仍会复核：

- 女仆所有权。
- 当前瞄准实体。
- 区域坐标。
- 面部中心与法向量。
- 实体交互距离和视线。

客户端按需捕获面部：相机 24 格内，且女仆正在进食、存在待发射粒子或开启 F3 + B 调试。
客户端喂食射线上限为 8 格；服务端再按玩家实体交互距离并附加少量容差复核。

### 饱和度已满

饱和度达到 100 时，普通食物、金苹果和整块蛋糕都会被服务端拒绝：

- 不消耗物品。
- 女仆看向主人并挥动副手。
- 播放拒绝音效。
- 显示“已经吃不下了……”气泡。

动作和音效使用 20 tick 冷却。

## 药品与经验物品

### 药水

普通右键将药水效果直接应用给女仆；非创造模式消耗药水并返还玻璃瓶。

### 牛奶桶

普通右键清除女仆当前药水效果；非创造模式返还空桶，并保留 TLM 对应进度触发。

### 玻璃瓶

玻璃瓶提取女仆经验仍由 TLM 本体执行。本模组只保证新的交互路由和准星提示不会拦截它。

## TLM 本体与其它模组物品

以下普通右键继续转交 TLM 或物品自身处理：

- 背包的穿戴与卸下。
- 鞍、智能符板和命名牌。
- 普通指南针的任务区域操作。
- 相机、仆人铃和模型切换器。
- 好感度工具。
- 其它模组实现的实体交互。

这里的“兼容”不表示本模组重新实现了这些功能。

## 准星提示

对准已驯服女仆时，TLM `MaidTipsOverlay` 会显示当前可用操作：

- 空手：坐下/起立、打开界面或下乘。
- 普通食物：仅在准星进入有效口部区域时显示喂食。
- 金苹果、蛋糕：提示对准面部喂食。
- 药水、牛奶、玻璃瓶：显示对应直接交互。
- 饱和度已满：显示不可继续喂食。

## 面部定向进食碎屑

以下进食会使用同一套面部碎屑：

- 玩家口部喂食成功。
- TLM Work Meal、Heal Meal、Home Meal。
- 附属自动进食。

表现：

- 每组 5 个物品碎屑。
- 尺寸约为原版的 75%，初速度减半。
- 从当前帧面部中心沿法向量向下偏转约 45° 发射。
- 普通自吃约 7 tick 后开始，每 4 tick 一组；快速食物不等待预热。
- 面部数据未就绪时最多等待 20 tick；进食已结束则丢弃，不延迟补喷。

附属会阻止女仆实体中心位置的旧版原版进食碎屑，避免两套效果重叠；
治疗、爱心等业务粒子仍然保留。

## 调试显示

开启 F3 + B 时：

- 面部四个顶点显示为红、绿、蓝、黄标记。
- 有效的 `40% × 20%` 口部区域显示为橙色平面。

这只用于判定调试，不改变服务端喂食范围。

相关客户端表现见[视觉表现、环境与物理](../visuals/README.md)。
