# 女仆行为手册

本手册集中列出“TLM：朝夕相伴”新增或改变的女仆行为，并按玩家理解方式拆分。
总索引只负责确认“有哪些行为”；触发条件、效果、优先级和限制写在对应分类文档中。

版本基线：Minecraft 1.20.1、Forge 47.4.0、Touhou Little Maid 1.5.3 或更高兼容版本。

## 收录范围

- 收录玩家能观察、操作或通过界面确认的行为。
- 收录没有新增动作、但改变了响应时机或选择顺序的 AI 行为。
- 收录本模组为 TLM 本体行为增加的交互路由或状态反馈。
- 不把缓存、Codec、网络包、Mixin 注入点等内部实现单独算作行为。
- 完全未修改的 TLM 本体行为不重复抄录；兼容入口会明确标注“由 TLM 执行”。

## 完整行为目录

### 陪伴与行动

1. 0.1 秒注视召回。
2. 抵达后的 3 秒指挥跟随。
3. 指挥期间共乘载具、寻找同类型/同家族玩家可坐空位或接替主人释放的位置。
4. 指挥座位/载具持久锁定及主人、危险、非 Home 超距传送释放。
5. 低饥饿时前往附近 TLM 零食柜并原子取出一份合法食物。
6. 缺食反馈触发与普通低饥饿主动求食。
7. 高好感低饥饿主动求食。
8. 内置任务完成后归队一次。
9. 随机游走时概率改为归队。
10. 由意图而非原版行为决定走向主人，超过 16 格才强制传送。
11. 主人静止时临时扩大空闲、工作和战斗活动半径。
12. 受击与主动扫描驱动的战斗目标预热。
13. 呼吸、回区、战斗、跟随、陪伴、工作、祈求、偷吃和拾取的移动意图协调。
14. 被动凳子、娱乐座和普通船只因跟随、拾取、主人离船或战斗需要自主下乘。
15. 授权后由命令或自主渡水需求激活的安全放船能力。
16. 同一主人下多名女仆对共享请求进行公平竞标并选出唯一响应者。
17. 从执行结果学习对象可靠性、主人偏好和时段习惯，并支持冻结、重置与导出。
18. 自由模式下自行决定何时去书架、棋盘或电脑前消遣，饿着时不去。

### 照料与状态

19. 独立饥饿值和饱和度消耗。
20. 手持/背包/附近零食柜食物自动进食。
21. 玩家喂食和 TLM 本体进食恢复附属饥饿值。
22. 基础饥饿回血和快速饱和回血。
23. 缺食物状态气泡与数据驱动求食信号。
24. 背包已满拾取反馈。
25. 主手/副手低耐久工具自动替换。
26. 无备用工具时告警和祈求。
27. 缺食、背包满、工具告急、换工具成功等状态气泡。

### 交互与物品

28. Shift + 右键打开女仆界面。
29. 空手右键切换坐下/起立。
30. 空手右键让女仆离开载具或放下乘客。
31. 手持物品只执行物品交互，不再兜底打开界面。
32. 动态口部区域喂食普通食物、金苹果和整块蛋糕。
33. 饱和度已满时拒绝喂食并给出动作、音效和气泡。
34. 药水直接使用、牛奶清除效果。
35. 玻璃瓶提取经验与其它 TLM 本体物品兼容。
36. 河童罗盘保留写入/清除日程位置的本体按键。
37. 准星交互提示。
38. 玩家喂食与女仆自吃时的面部定向碎屑。
39. Gecko、Bedrock 和可访问 YSM 模型的动态面部平面。
40. F3 + B 面部顶点与喂食区调试显示。

### 成长与进度

41. 女仆独立 1–50 级成长。
42. 经验球、进度奖励和命令等经验来源。
43. 升级聊天通知。
44. 详情提示中的等级、经验和好感等级。
45. 女仆界面中的饥饿条与饱和度层。
46. 每只女仆独立的原版/模组进度镜像。
47. 喂食、等级、好感和累计经验自定义触发器。
48. 女仆行为桥接战斗、世界、工具、繁殖和蜂蜜块等原版触发器。
49. 女仆专属进度 Tab 和可拖动进度树。

### 外观与客户端表现

50. Gecko 头发、尾巴、耳朵、裙摆等骨骼二级摆动。
51. Gecko 物理的碰撞代理、裙摆链和作者姿态恢复。
52. Gecko 物理开启时，由维度、天气、海拔、室内和浸水影响的程序化风。
53. Gecko 逐面外法线、绕序和 Sodium 法线修正。
54. 阻止客户端虚假随机回血造成的血条闪烁。

## 阅读约定

- “新增”表示 TLM 本体没有该行为。
- “改变”表示本模组调整了触发、按键、优先级或反馈。
- “兼容”表示行为仍由 TLM 或其它模组执行，本模组只保证入口不被拦截。
- 数值若来自 Data Pack，以当前服务端加载结果为准；本文记录内置默认值。

开发者需要修改行为时，再进入
[数据驱动意图 AI](../architecture/intent-ai-data.md)、
[多版本架构](../architecture/README.md)或各系统专章。
