# 女仆行为手册

本手册集中列出“TLM：朝夕相伴”新增或改变的女仆行为，并按玩家理解方式拆分。
总索引只负责确认“有哪些行为”；触发条件、效果、优先级和限制写在对应分类文档中。

版本基线：Minecraft 1.20.1、Forge 47.4.0、Touhou Little Maid 1.5.3 或更高兼容版本。

## 收录范围

- 收录玩家能观察、操作或通过界面确认的行为。
- 收录没有新增动作、但改变了响应时机或选择顺序的 AI 行为。
- 收录本模组为 TLM 本体行为增加的交互路由或状态反馈。
- 不把缓存、Codec、网络包、Mixin 注入点等内部实现单独算作行为。
- 完全未修改的 TLM 本体行为不重复抄录；兼容入口会明确标注“由 TLM 执行”。

## 完整行为目录

### 陪伴与行动

1. 0.1 秒注视召回。
2. 抵达后的 3 秒指挥跟随。
3. 指挥期间共乘载具、寻找邻座或接替主人释放的位置。
4. 指挥座位/载具持久锁定及主人、危险释放。
5. 普通饥饿主动求食。
6. 高好感低饥饿主动求食。
7. 内置任务完成后归队一次。
8. 随机游走时概率改为归队。
9. 主人静止时暂缓打断受保护任务的普通跟随。
10. 主人静止时临时扩大空闲、工作和战斗活动半径。
11. 受击与主动扫描驱动的战斗目标预热。
12. 呼吸、回区、战斗、跟随、陪伴、工作、祈求、偷吃和拾取的移动意图协调。
13. 被动凳子/娱乐座因跟随、拾取或战斗需要自主离座。

### 照料与状态

14. 独立饥饿值和饱和度消耗。
15. 手持/背包食物自动进食。
16. 玩家喂食和 TLM 本体进食恢复附属饥饿值。
17. 基础饥饿回血和快速饱和回血。
18. 缺食物时近距离祈求。
19. 背包已满拾取反馈。
20. 主手/副手低耐久工具自动替换。
21. 无备用工具时告警和祈求。
22. 缺食、背包满、工具告急、换工具成功等状态气泡。

### 交互与物品

23. Shift + 右键打开女仆界面。
24. 空手右键切换坐下/起立。
25. 空手右键让女仆离开载具或放下乘客。
26. 手持物品只执行物品交互，不再兜底打开界面。
27. 动态口部区域喂食普通食物、金苹果和整块蛋糕。
28. 饱和度已满时拒绝喂食并给出动作、音效和气泡。
29. 药水直接使用、牛奶清除效果。
30. 玻璃瓶提取经验与其它 TLM 本体物品兼容。
31. 河童罗盘保留写入/清除日程位置的本体按键。
32. 准星交互提示。
33. 玩家喂食与女仆自吃时的面部定向碎屑。
34. Gecko、Bedrock 和可访问 YSM 模型的动态面部平面。
35. F3 + B 面部顶点与喂食区调试显示。

### 成长与进度

36. 女仆独立 1–50 级成长。
37. 经验球、进度奖励和命令等经验来源。
38. 升级聊天通知。
39. 详情提示中的等级、经验和好感等级。
40. 女仆界面中的饥饿条与饱和度层。
41. 每只女仆独立的原版/模组进度镜像。
42. 喂食、等级、好感和累计经验自定义触发器。
43. 女仆行为桥接战斗、世界、工具、繁殖和蜂蜜块等原版触发器。
44. 女仆专属进度 Tab 和可拖动进度树。

### 外观与客户端表现

45. Gecko 头发、尾巴、耳朵、裙摆等骨骼二级摆动。
46. Gecko 物理的碰撞代理、裙摆链和作者姿态恢复。
47. Gecko 物理开启时，由维度、天气、海拔、室内和浸水影响的程序化风。
48. Gecko 逐面外法线、绕序和 Sodium 法线修正。
49. 阻止客户端虚假随机回血造成的血条闪烁。

## 阅读约定

- “新增”表示 TLM 本体没有该行为。
- “改变”表示本模组调整了触发、按键、优先级或反馈。
- “兼容”表示行为仍由 TLM 或其它模组执行，本模组只保证入口不被拦截。
- 数值若来自 Data Pack，以当前服务端加载结果为准；本文记录内置默认值。

开发者需要修改行为时，再进入
[数据驱动意图 AI](../architecture/intent-ai-data.md)、
[多版本架构](../architecture/README.md)或各系统专章。
