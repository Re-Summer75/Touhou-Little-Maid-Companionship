## 表情系统概览

| 类型 | 是否有统一池 | 是否有状态语义 |
| --- | --- | --- |
| 图片表情 | 有 | 没有，只按资源随机选择 |
| 颜文字 | 有 | 有工作、空闲、睡眠、受伤四类 |
| 模型面部表情 | 没有 | 由模型骨骼和动画脚本自行定义 |

## 自动触发流程

```text
EntityMaid.aiStep
→ ChatBubbleManager.tick
→ RandomEmoji.tick
→ 按配置权重选择图片表情或颜文字
```

默认配置：

| 配置 | 默认值 |
| --- | --- |
| `EnableEmoji` | `true` |
| `EmojiCheckRate` | 1200 tick，约 60 秒 |
| `ImageEmojiWeight` | 10 |
| `KaomojiEmojiWeight` | 10 |
| 默认图片与颜文字比例 | 各约 50% |
| 气泡持续时间 | 300 tick，约 15 秒 |
| 单个女仆最多保存气泡数 | 5 |

普通随机表情只会在当前没有气泡时添加。每个女仆还会根据 UUID 错开检查时间，避免大量女仆同时显示表情。

受伤颜文字使用独立路径：触发 `MaidDamageEvent` 且当前没有气泡时，直接选择 `hurt` 池，不参与图片和颜文字的权重随机。

## 开发结论

1. 普通气氛表情可以直接复用原版随机图片池。
2. 工作、空闲、睡眠和受伤可以复用原版颜文字池。
3. 生命告急、工具损坏、工作完成等明确状态应由附属维护语义化表情。
4. 跨模型表达情绪时优先使用气泡，不应依赖模型私有面部骨骼。
